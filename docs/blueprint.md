# **App Name**: Bung'Kurir

## Core Features:

- Map Plane Dashboard: Create specific delivery sessions like 'Gas Pagi' or 'Keliling Kota Dolo' using interactive markers.
- Smart Link Decoder Tool: Use an AI tool to automatically parse coordinates and buyer info from messy WhatsApp share-links or addresses.
- One-Tap Ops Action: Large interactive buttons for 'Buka Jalan' (Google Maps nav) and 'Chat Dulu' (WhatsApp API).
- Status-Aware Markers: Color-coded LeafletJS markers: Red (Belum Antar), Grey (Su Selesai), and Green (Uang Lebih).
- COD Ledger & Tip Tracker: Calculates payment gaps for the 'Uang Lebih' feature when a buyer pays more than the invoice.
- Browser-Sync Storage: Manage persistence using browser localStorage to keep all courier data available without an internet database.
- Real-time Kurir Summary: Localized dashboard showing total packets and cash-on-hand using Eastern Indonesian dialect.

## Style Guidelines:

- Primary color: Deep Field Blue (#1565C0) to evoke reliability and professionalism in the courier industry.
- Background color: Dark Oceanic Navy (#0B121E) used for a high-contrast dark theme optimized for low-eye strain in the field.
- Accent color: Tropical Cyan (#00A3C1) for call-to-action buttons, analogous to the primary blue for a harmonious flow.
- 'Inter' font used throughout for high readability and a machined, objective look suitable for map dashboards.
- Mobile-first glassmorphism layout with oversized touch targets and soft blue glows to accommodate field work ergonomics.
- Smooth status transitions and horizontal drawer slides for the buyer sidebar using subtle ease-in-out effects.
- Thick, high-contrast monochrome icons paired with the vivid Orange highlight specifically for 'Uang Lebih' alerts.
